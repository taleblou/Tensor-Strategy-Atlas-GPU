# Contributing

Before adding an implementation:

1. Place it under the correct `architectures/<family>/<architecture_id>/` directory.
2. Add or update its row in `manifests/ARCHITECTURE_INVENTORY.csv`.
3. Record source provenance and license.
4. Keep correctness evidence separate from benchmark claims.
5. Do not claim a performance winner without comparable measured evidence.

Pull requests should explain semantics, provenance, supported hardware, and validation status.
